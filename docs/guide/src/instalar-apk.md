# Instalar la app Android

La app se publica como un archivo APK en la página de
[Releases de GitHub](https://github.com/maxiusofmaximus/herdr-notify/releases).

## Pasos

1. En el móvil, abre la página de Releases y entra en la última versión.
2. Descarga el archivo `.apk` de esa versión.
3. Ábrelo desde las descargas. Android pedirá permiso para instalar apps desde esa
   fuente. Concédelo solo para el navegador o el gestor de archivos que estás usando.
   El texto de esa pantalla cambia según la versión de Android.
4. Confirma la instalación.

## Actualizar

Instala el APK nuevo encima de la versión anterior. El emparejamiento se queda en el
móvil. Si después de actualizar la app no reconoce tu PC, [empareja de nuevo](emparejar.md).

Si Android rechaza la instalación por conflicto de firma, desinstala primero la versión
anterior. Al desinstalarla se borra también el emparejamiento, así que tendrás que emparejar
de nuevo.

## Siguiente paso

Con la app instalada, [prepara el host en tu PC](instalar-host.md) y luego
[empareja el móvil](emparejar.md).
