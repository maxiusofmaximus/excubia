# Instalar la app Android

La app se publica como un APK en la página de
[Releases de GitHub](https://github.com/maxiusofmaximus/herdr-notify/releases).
La última versión es la **v1.0.1** y el archivo se llama `herdr-notify.apk`.

## Pasos

1. En el móvil, abre la página de Releases y entra en la última versión.
2. Descarga `herdr-notify.apk`.
3. Ábrelo desde las descargas. Android pedirá permiso para instalar apps desde esa
   fuente. Concédelo solo para el navegador o el gestor de archivos que estás usando. El texto de esa pantalla cambia según la versión de Android.
4. Confirma la instalación.

La app también se puede instalar y actualizar desde MaxApps Hub, que lee las versiones
publicadas en esta misma página de Releases.

## Actualizar

Instala el APK nuevo encima de la versión anterior (o actualiza desde MaxApps Hub): el
emparejamiento se queda en el móvil. Si después de actualizar la
app no reconoce tu PC, [empareja de nuevo](emparejar.md).

## Siguiente paso

Con la app instalada, [prepara el host en tu PC](instalar-host.md) y luego
[empareja el móvil](emparejar.md).
